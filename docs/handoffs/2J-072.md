- La API es la autoridad. Las capacidades `entitlements.read/manage` se añadieron al catálogo, pero los grants no se amplían: actualmente quedan disponibles para Admin conforme a la matriz existente. Trainer/Reception/Management no recibirán capacidad nueva por esta TASK.
- Precio y fecha de vencimiento se capturan en la venta porque el catálogo no guarda precios.

- La asignación no concede consumo de reservas ni altera el comportamiento del calendario.
