# 2J-SP1-01 — Kit de release y staging interno de Admin

## Objetivo

Preparar un candidato verificable para Admin y dejar un camino de staging seguro, sin habilitar acceso público ni alterar el comportamiento de producto.

## Aceptación de esta entrega

- Preparación manual `PrepareOnly`, sin red, despliegue ni migraciones.
- Artefacto con commit/tree, hashes SHA-256, frontend y API compilados.
- Rechazo de rutas de secretos/datos locales y de manifiestos que no indiquen piloto interno, fiscal cerrado y sin exposición pública.
- Pruebas del generador de manifiestos.
- Requisitos de servidor/DNS y bloqueos de staging documentados.
- El modo de venta de contratos y el gate fiscal permanecen cerrados.

## Fuera de esta entrega

Despliegue remoto, configuración DNS/TLS, secretos, migraciones reales, activar fiscalidad y publicar autenticación demo. La activación remota requiere autenticación de personal apta para servidor y aprobación del destino de staging.
