# RM-00-01 — Reset scroll and focus on professional module change

## Objective
When the professional shell switches module, the page starts at the top and focus moves to the new page's `h1`. Source: `COMPETITIVE-IMPROVEMENT-ROADMAP-V2.md` RM-00-01 (audit row T1, P0, XS).

## Problem
Measured on the pilot: Tienda scrolled down → Resumen leaves the page scrolled (`scrollY` 330) and the `h1` 234 px above the viewport. The shell keeps the previous scroll position and does not move focus.

## Scope
- A small hook in `apps/admin-web/src/route-focus.ts`, called once from `App` in `main.tsx` with the current module id (hash id without query string).
- Resets the real scroller (`document.scrollingElement`: the document; `.app-frame`, `.app-content` and `.app-page` do not scroll) and focuses `.app-page h1` with `preventScroll`.
- `tabindex="-1"` is added to the heading at runtime; a `:focus-visible` ring matching `.client-name` is added in `shell-v2.css` (pointer navigation shows nothing).
- Waits (≤ 3 s) for pages that render their `h1` after loading; does not take focus from a field the user is already using.
- Drawer layout (< 1024 px): the shell returns focus to its menu button after closing the drawer; the hook keeps focus on the new heading.
- Tests: `apps/admin-web/test/route-focus.test.mjs`.

## Out of scope / stop conditions
- No routing or navigation change, no layout or visual change, no scroll restoration system (Back/Forward start at the top, same as a main-navigation entry).
- No Clientes, Cliente 360, Resumen, Agenda, Servicios or Tienda changes; no API, DB, migrations, RBAC, Member or 098E.
- No RM-00-02 or other roadmap items in this PR.

## Acceptance
- Module change resets scroll and focuses the new `h1` for Admin and Trainer, at 1440, 1024, 768 and 390 px.
- Modal open/close, local tabs, typing and query-only hash changes do not reset scroll or move focus.
- Tests, typecheck and build pass; agent-browser run on the pilot (Tienda → Resumen and a second long module).
- Handoff: `docs/handoffs/RM-00-01.md`. No owner gate.
