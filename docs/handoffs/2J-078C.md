## Security boundaries

Subject values are opaque, excluded from responses and audit detail, and cannot be reassigned after revocation in V1. Self-service routes require an injected active subject resolver and cannot accept caller-supplied `personId`.

Challenge values are 32 random bytes, returned once, stored only as SHA-256, expire within five minutes, and are bound to person, active subject, audience, purpose, and request ID. Idempotent replays return no challenge. Transactions never create a canonical Training link. Verification is an internal gated service method only: there is no public proof endpoint, Training verifier, remote ACK, or remote traffic.

The service client and signature helper are dormant. The three gates are independent and default false. The service signature canonical form and future receiver responsibilities are described in `tasks/2J-078C.md`.
