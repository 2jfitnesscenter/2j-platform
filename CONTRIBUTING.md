# Contributing

Use Node 24 and pnpm 10.34.6. One TASK per branch and PR. Stacked PRs explicitly name their base/dependency; retarget only after prerequisite review/merge. main is stable. No automatic merges in Phase 0. Juanjo approval is mandatory for high/critical, architecture, migrations, auth, permissions, financial, health, destructive and transversal UI changes. Reviewer cannot approve their own medium/high/critical implementation. Keep source decisions in research repo; document outcomes here.
