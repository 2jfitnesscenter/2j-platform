Training response contains `v`, opaque `trainingUserId`, active status, `asOf`, optional current program `{id,name}`, and recent activity `{lastTrainingAt,sessionsLast30Days}`. Platform member response strips the remote user ID and program ID. No workouts, health/body metrics, coach notes, or permissions cross the boundary.
