## Delivered

- Replaced the primary navigation with Inicio, Búnker, Tienda, Perfil, Ajustes.
- Inicio contains exactly three primary blocks: Noticias, Reservar clase, Próxima reserva. Booking CTA opens the existing weekly reservation UI; the next-booking block selects one future `reserved` record, excludes waitlist/cancelled/past entries, shows its service, local date/time range, area and confirmation state, and links to reservation history.
- Noticias temporarily reads the newest `center_notice` from Member notifications. Notifications remain a separate domain and the source is documented as interim.
- Búnker links to the existing Training app in a new tab. Tienda has only informational category cards and no implied catalog or prices. Perfil retains current member profile, membership/right balances, forms and consents, with a Buzón link. Ajustes is a restrained empty general-settings shell; pilot links remain development/preview-only.
- Preview remains explicitly fixture-only and makes no API requests. Booking pilot auth, cohort gate, reserve/cancel/waitlist behavior and server authorization were not changed.
