# A74/A76 — Caja anterior, fichaje y motivo de ajuste

Base actualizado tras integrar PR #184: `82e0590893b0e55db5905c722b8870dce26368c1`.

## Reglas aplicadas

- Una sesión de caja anterior se muestra como aviso en el listado: «Caja de ayer sin cerrar: ciérrala o traspásala».
- La caja previa no bloquea abrir otra caja, cerrar con recuento por denominaciones, traspasar ni fichar salida.
- Cerrar una caja requiere recuento a ciegas; el importe esperado y la diferencia siguen siendo exclusivos de `owner.panel.read`.
- La migración `0070_cash_previous_day_warning.sql` elimina el trigger DB que acoplaba `clock_out` a la custodia y conserva la validación D113 para ventas/cobros en efectivo del día actual.
- El motivo de ajuste se exige solo cuando el precio de venta difiere del precio de catálogo. La UI ya aplicaba esta condición; se mantiene cubierta por regresión UI y API.

## Recorrido sintético de negocio (verificado localmente mediante API y UI tests; sin datos reales)

1. El personal ficha entrada y abre Búnker/Sala con recuento inicial por denominaciones.
2. Se registra una venta POS con caja abierta; se verifica el vínculo de la venta con el turno y el total de caja (test `D113 blocks paid POS sales without an open shift and links cash sales into the shift total`).
3. Se realiza el cambio de turno con dos recuentos; la persona saliente puede fichar salida sin cerrar la caja si la custodia ya se transfirió (test `two physical registers have isolated custodians, blind counts, handover and owner-only daily totals`).
4. Se cierra una caja del día anterior con recuento ciego, se abre otra caja y se ficha salida sin que el turno de caja lo impida (tests `previous-day cash does not block opening another register or clocking out` y `two physical registers have isolated custodians, blind counts, handover and owner-only daily totals`).
5. Se asigna un plan al precio publicado sin motivo, se rechaza un precio distinto sin motivo y se completa una reserva de cliente (tests `sale price override requires catalog pricing permission and a reason`, `unchanged price...` y `staff can reserve and cancel a client`).
