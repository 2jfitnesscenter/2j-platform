## Correcciones consolidadas

- Reasignación de sustituciones limita los cambios a sesiones futuras, `scheduled`, propiedad del origen y totalmente dentro del rango; conflictos y selección se validan en transacción. Cada sesión reasignada conserva auditoría con sesión, profesional anterior/nuevo y sustitución; actor y hora están en el envelope de auditoría.
- Correcciones de fichaje se serializan bloqueando profesional y evento, guardan revisión monotónica, valor previo efectivo y nuevo valor; soportan varias correcciones y restauración del original. La cronología completa se revalida contra eventos vecinos y rechaza valores futuros; el evento original nunca cambia. La inserción manual usa el mismo validador de línea temporal y rechazo de futuro.
- La migration 0009 backfillea revisión histórica de correcciones y crea índice único por evento/revisión; añade barreras de DELETE/TRUNCATE para profesionales, tramos, excepciones y sustituciones. Se mantienen transacciones y bloqueos API para solapes; se evita una extensión `btree_gist`/exclusion constraint que complicaría el despliegue de esta migración.
- Excepciones derivan las fechas locales en servidor desde instantes y `Atlantic/Canary`; entradas de fechas inexistentes o incoherentes se rechazan con error controlado, con casos DST de marzo/octubre.
- Disponibilidad une tramos contiguos y `extra_availability` puede cubrir una sesión fuera del horario habitual, manteniendo controles de ausencia y conflicto. Las fechas de calendario y jornada se calculan en Canary.
- Roles/capacidades actualizados: Admin completo; Reception/Management gestiona horarios, ausencias, sustituciones y operación necesaria; Trainer consulta disponibilidad y usa su propio fichaje, sin administrar perfiles ajenos, roles, enlaces de cuenta, PII de contacto, notas internas ni auditoría; Accountant carece de acceso operativo. PII y notas se filtran en servidor.
- La UI incluye edición/archivo de profesional, archivo de tramo, cancelación de ausencia con historial, selección y reasignación explícita de sesiones de sustitución, feedback/confirmaciones, tabs accesibles con teclado y foco/scroll al perfil en móvil. El dashboard muestra el estado de jornada cuando está disponible.
- La API de enlace de cuenta conserva control Admin-only, unicidad y auditoría old/new con confirmación de reemplazo. No hay directorio/proveedor de identidad en este repositorio, así que no se inventó un selector ni se expuso un `authActorId` crudo; se registra como bloqueo de integración para cuando exista el directorio.
