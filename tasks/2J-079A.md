# 2J-079A — 2J Hub Client Preview / Safe Parallel Pilot

## Objective

Add an optional mobile-first member Hub while keeping the existing Training app at `https://app.2jfitnesscenter.com` unchanged and independently accessible. Preserve the existing client API flows, provide an explicitly gated fixture preview, and expose staff/admin only as separate internal pilot surfaces.

## Acceptance

- Member navigation has exactly five destinations: Inicio, Reservar, Entrenar, Centro, Perfil. Notifications remain in the header; reservation history is reached from Reservar.
- Existing API-backed member data and actions remain in normal mode. Missing identity/API access fails closed; the UI does not synthesize successful real-mode actions.
- Training opens the existing application in a separate browser context, with no iframe, shared cookie, SSO, or Training data writes.
- `VITE_2J_HUB_PREVIEW=true` plus `?preview=1` enables fictional data only; preview makes no API calls and disables or locally simulates mutations.
- Internal pilot links are separate from member navigation and gated to development/preview builds. Backend authorization remains authoritative.
- Pilot diagnostics contain only app/build version, current view, timestamp, viewport and environment; no PII or credentials.
- Document the current state of member/staff/admin testing and exact deployment blockers for `inicio.2jfitnesscenter.com`.
- Do not configure DNS, TLS, proxy, or production hosting; do not modify or deploy `2jfitnessapp`.
