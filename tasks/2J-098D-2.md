# 2J-098D-2 — Subida, variantes y API de imágenes de producto

> Lee primero `docs/architecture/epics/2J-098-master.md` (sección `STORE MEDIA MODEL`) y el handoff de D-1.

## Objective

Implementar la subida, el procesado, la gestión (principal, orden, reemplazo, borrado) y el servido de imágenes de producto, con permisos y sin binarios en PostgreSQL.

## Context

D-1 entregó el puerto, las tablas y el spike. El catálogo Member y la gestión Admin ya existen sin imágenes.

## In scope

1. `POST /api/admin/store/products/:id/images` (multipart ≤ 8 MB, `store.catalog.manage`): validación por bytes mágicos (JPEG/PNG/WebP; SVG rechazado), límite de píxeles, orientación automática, **EXIF eliminado**, reencodado a variantes WebP, concurrencia de procesado limitada, `Idempotency-Key` y `sha256` por producto. Máximo 6 por producto.
2. Gestión: reordenar, fijar principal (intercambio atómico de posición), texto alternativo, reemplazo (asset nuevo + intercambio atómico), borrado lógico.
3. Servido autenticado `/api/me/store/media/:assetId/:variant` con ETag por hash de contenido, caché privada y `X-Content-Type-Options: nosniff`; el catálogo Member y la gestión Admin devuelven `images` (vacío para productos antiguos).
4. Auditoría de subida/reemplazo/borrado en `platform_domain_audit_events` (dominio `media`).
5. Límites de tasa en subida.

## Out of scope

UI (D-3); limpieza de huérfanos programada (D-3); imágenes por variante; ecommerce.

## Dependencies

D-1.

## Domain invariants

- Máximo 6 imágenes vivas por producto; exactamente una principal si hay alguna.
- Reemplazar o reordenar es atómico: nunca queda un producto sin principal ni con dos.
- Ningún archivo no re-encodado se sirve; ningún EXIF/GPS sobrevive.
- Solo quien tiene `store.catalog.manage` sube o modifica; el Trainer recibe 403 por defecto.
- Productos sin imágenes siguen funcionando sin cambios.

## Files likely affected

`apps/api/src/store.ts`, `apps/api/src/media/*`, `apps/api/migrations/` (si hace falta), tests de tienda.

## Migration

Ninguna adicional salvo ajustes menores sobre D-1.

## Feature flags

`store.images.enabled`.

## Tests

- Formato falso con extensión válida; imagen enorme en píxeles; SVG; EXIF con GPS eliminado.
- Subida duplicada idempotente; séptima imagen rechazada.
- Reemplazo y cambio de principal atómicos, incluso con subidas concurrentes.
- Permisos (Admin sí, Trainer 403); producto inexistente.
- Fallo entre escritura del blob y commit de BD → el blob queda huérfano y detectable.
- Servido: ETag/304, `nosniff`, autenticación.

## Manual acceptance

Sin UI visible en esta task; se verifica con peticiones y con el piloto una vez llegue D-3.

## Risks

Subida concurrente que rompa la posición única → transacción y tests; CPU del procesado → semáforo.

## Definition of Done

API completa con permisos y auditoría; tests verdes; revisión de SHA exacto; handoff.
