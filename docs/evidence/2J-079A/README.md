# 2J-079A visual evidence

The Hub was opened in its gated fixture mode at `http://127.0.0.1:5180/?preview=1` and visually inspected in the browser for Inicio, Reservar, Entrenar, Centro, and Perfil. The rendered browser screenshots during review show the five-item mobile navigation, fictional-data badge/copy, appointment list, external Training handoff, and internal-only staff/admin links.

The available browser session has no supported viewport-size override, and its screenshot API returns an image to the review session without a repository file export path. Therefore this folder intentionally contains no fabricated or mislabelled 1440, 768, or 390 px screenshots. Dimension-specific captures remain an independent UX-review follow-up before wider pilot use.

The fixture preview displays fake data only. It makes zero API calls and does not persist reservation, waitlist, profile, document, consent, or notification changes.
