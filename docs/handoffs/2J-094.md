## Technical and accessibility notes

- Navigation source is the existing capability endpoint; role strings are not used for visibility.
- Direct routes remain governed by the existing server checks.
- Group toggles are buttons with `aria-expanded`; destinations are links and current route uses `aria-current`. Active groups and keyboard focus are visible. Search remains available independently of the Command Center read model.

The token set defines a dark palette through `:root[data-theme="dark"]`; Admin currently has no user-facing theme selector/runtime toggle, so dark visual runtime activation could not be performed through the supported application UI. Do not claim a browser-verified dark screenshot until a supported theme control exists.
