## Model found and changes

Before this work, `client_plan_assignments` represented the client/plan-version contract and stored its date range and one linked charge. There was no separate monthly period entity. `economic_charges` represented obligations and `economic_transactions` held immutable payment/refund movements whose net state is derived. `client_entitlement_ledger` recorded append-only grants, consumption, restores, adjustments, and expirations. `calendar_reservation_rights` connected a reservation to the selected right and its consume entry. `period_quota` was a booking cap, not a session bag.

Migration `0033_assignment_entitlement_periods.sql` adds optional `weekly_frequency` to versioned session quota rights; immutable monthly period snapshots; append-only recurrence and period events; and period-scoped ledger and reservation links. Legacy rights with no frequency continue through the existing assignment ledger path. `period_quota` semantics remain unchanged.

The Platform API initializes the first natural-month period, permits audited future-only recurrence changes to Admin and Trainer, and lets authorized billing staff link an existing charge. Full settlement validation activates the linked bag, prorating late settlement from its effective `Atlantic/Canary` date. A worker materializes no more than the immediate next period and never creates a charge. The effective-entitlement API and booking server enforce period access. Provisional bookings remain confirmed; if late proration leaves a non-positive balance, new bookings are blocked without removing history.

A single assignment charge may cover multiple session-quota rights only when they belong to the same assignment and exact period window. Each right has its own bag, payment-validation event, and deterministic materialization key.

The work does not add UI for period initialization or charge linking. It does not add Home/Búnker/Training integration, account or identity changes, automatic charges, penalties, rollover, or `period_quota` conversion.
